Hexagonal Numbers as Repdigits

Interactive companion for proposed OEIS A402645 · Peter M. Chema · Review copy
Hexagonal number H(n) = n(2n − 1)
Number of valid two-digit repdigits a(n)

All valid representations

For a repeated digit d in base b, (dd)b = d(b + 1). We require 1 ≤ d < b and b ≥ 2. Digits ≥ 10 are displayed as numeric digit pairs (d,d), not conventional single-character numerals.

Divisor-counting check

Here τ(m) denotes the number of positive divisors of m.

Formula: a(n) = floor(τ(H(n))/2) − e(n), where e(n) = 1 exactly when H(n) = k(k + 1) for some positive integer k, otherwise 0.

The exceptional indices satisfy (4n − 1)² − 2(2k + 1)² = −1. The first are n = 2, 60, 2030, 68952, ...
